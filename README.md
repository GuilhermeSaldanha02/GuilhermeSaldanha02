## 📂 Projetos em destaque

### 🏢 Audicon — gestão condominial com IA
API multi-tenant em NestJS, TypeORM e PostgreSQL, com JWT, rate limiting, Swagger, CI com testes unitários e E2E e análise de infrações com a API do Gemini. Front em Next.js.
[API](https://github.com/GuilhermeSaldanha02/audicon-backend) · [Web](https://github.com/GuilhermeSaldanha02/audicon-web) · [Demo](https://audicon-web.vercel.app)

### 🏋️ Lastro — acompanhamento de treino para alunos e personal trainers
PWA offline-first em Next.js, React e TypeScript, com Supabase/PostgreSQL (88 migrações e mais de 50 políticas de RLS), análise por IA (Gemini), mais de 3.000 testes (Vitest) e testes E2E (Playwright). Desenvolvido com assistência de IA e revisão minha.
🔒 Repositório privado — código disponível em entrevista.

### 🎬 Radar Quente — automação de vídeos curtos
Pipeline em Node.js, em camadas, que grava lives, gera cortes verticais com legenda, usa IA para escolher, escrever o gancho e revisar, e agenda a publicação. Cerca de 230 casos de teste.
🔒 Repositório privado — código disponível em entrevista.
